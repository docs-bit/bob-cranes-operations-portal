# Light Equipment-Operations Theme Reference Notes

The supplied reference uses a **soft off-white canvas**, a large white dashboard surface, and subtle pale-gray section boundaries. It creates hierarchy with space, gentle shadows, and rounded modules instead of heavy dark panels. The portal translation will keep task-dense work areas easy to scan, with white cards, restrained borders, and low-elevation shadows.

The principal accent is a warm equipment orange. It is used for the selected navigation tab, primary data bar, active metric tile, route trace, location markers, and high-intent actions. The replacement theme will reserve orange for current state, primary actions, and actionable operational values; green, amber, and red will continue to communicate positive, warning, and critical safety states.

Typography is compact and clean, with strong dark headings, smaller neutral metadata, rounded search and filter controls, and circular icon actions. The portal will use a calm sans-serif hierarchy, pill-shaped filters where scan speed is useful, rounded panels, light form inputs, and visible orange focus treatment.

The reference presents equipment information through an overview board, telemetry summaries, equipment facts, route/alert modules, and a bar-style performance chart. Rather than fabricate live telemetry or map data, the existing real booking, completion, compliance, and crew information will receive the same structured card hierarchy and orange-progress treatment.
